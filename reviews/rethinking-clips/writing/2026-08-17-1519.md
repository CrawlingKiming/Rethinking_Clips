# Batch-size selection and adaptive-rule self-review

## Claim-evidence map

| Claim | Evidence | Status |
|---|---|---|
| The preferred estimator depends jointly on ESS and estimator size | Exact crossover theorem plus calibrated risk estimates at N = 128, 256, 512, and 1024 | Supported in the controlled task |
| N = 128 is not an informative adaptive regime | The calibration fit selects PPO throughout at N = 128 and N = 256 | Reported as a boundary case |
| N = 512 supports an ESS-dependent raw-versus-PPO choice | The fit-only boundary is 0.417 and selects both estimators before held-out evaluation | Supported without held-out selection |
| The calibrated ESS rule improves held-out gradient risk | Fitted ESS reduces per-state MSE by 4.3% +/- 1.1% relative to the better static estimator across 28 test states | Supported |
| The rule improves repeated policy optimization | Final reward is 0.4961 +/- 0.0003 for fitted ESS, 0.4606 +/- 0.0098 for raw, and 0.4038 +/- 0.0005 for PPO across 100 paired runs | Supported in the controlled task |
| A fixed normalized-ESS threshold is universal | N = 128 and N = 1024 produce opposite static regimes, and fixed 0.1 is weaker in held-out risk | Explicitly rejected |

## Contribution

1. **Pass.** The work now contributes a complete chain from effective support to gradient MSE, estimator choice, and repeated policy optimization.
2. **Pass.** The N-dependent boundary is necessary rather than cosmetic because averaging changes covariance but not clipping bias.
3. **Pass.** The adaptive regime is selected on calibration states only, so the main N is not chosen from held-out performance.
4. **Pass in scope.** The controlled result is stronger than the earlier one-size comparison because it includes all four candidate sizes and retains the static boundary cases.
5. **Open for transfer.** The LLM claim still requires the matched RLVR runs shown as placeholders.

## Experimental strength

2. **Pass.** Relative MSE is computed within state before aggregation, preventing high-scale states from dominating the percentage comparison.
3. **Pass.** The repeated-optimization study uses 100 paired runs and reports final reward, relative improvement, paired differences, and intervention frequency.
4. **Pass.** The fitted rule beats both static choices and is not merely a sample-efficiency tie.
5. **Open for external validity.** More tasks and policy classes are needed before claiming a universal threshold or universal dominance.

## Method design soundness

1. **Pass.** The fit/test split is stratified within every ESS interval.
2. **Pass.** The informative N criterion requires an interior fit-state boundary and is applied before held-out evaluation.
3. **Pass.** The formula estimates PPO variance and squared bias separately, including finite-M bias correction.
4. **Pass.** Paired estimators share prompts, responses, rewards, and advantages, while standard errors use policy states or replications as independent units.
5. **Pass in scope.** The controlled task preserves the RLVR rollout, grouped-response, sequential-minibatch, repeated-epoch, and policy-refresh structure.

## Reviewer-facing conclusion

The strengthened evidence supports a precise claim. Normalized ESS is useful after estimator size is specified, and a calibration-fitted ESS boundary can outperform both always-raw and always-PPO updates in the controlled RLVR loop. N = 128 is a legitimate always-PPO boundary case, not the main adaptive regime. The remaining claim requiring new evidence is transfer to language-model RLVR.
